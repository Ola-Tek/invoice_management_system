An easy-to-use and efficient Invoice Management System designed to help businesses and individuals create, manage, and track invoices seamlessly. 
This system provides features like invoice creation, client management, payment tracking, and report generation.
Features

✅ User Authentication – Secure login and registration.

✅ Client Management – Add, edit, and manage customer records.

✅ Invoice Creation – Generate invoices with unique IDs, due dates, and itemized details.

✅ Payment Tracking – Mark invoices as paid/unpaid and track payment history.

✅ Export Options – Download invoices as PDF/Excel.

✅ Search & Filter – Quickly find invoices by date, client, or status.

✅ Dashboard & Reports – View revenue summaries and pending payments.
Tech Stack

Backend: Django / Django REST Framework

Database: mongodb

Authentication: Django Authentication System

Frontend (optional): Django Templates
